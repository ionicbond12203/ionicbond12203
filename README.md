## Current Engineering Work

### [Open AI Co-Scientist](https://github.com/Siong23/ai-co-scientist) — Contributor

An open-source implementation inspired by Google's AI Co-Scientist work. The project uses specialized Generation, Reflection, Ranking, Evolution, Proximity, and Meta-Review agents to generate, assess, rank, and iteratively improve research hypotheses. It combines scientific-literature retrieval, evidence grounding, local LLM inference through LM Studio, and a Gradio interface.

My merged contributions include:

- Improved [multi-source RAG and full-text indexing](https://github.com/Siong23/ai-co-scientist/pull/64): concurrent literature retrieval, downloadable-paper ingestion, chunking and embedding, persistent ChromaDB indexing, evidence gates, and source telemetry.
- Strengthened [research-planning retrieval](https://github.com/Siong23/ai-co-scientist/pull/78) with hypothesis-guided queries, support/counterevidence/prior-art intents, query-fidelity checks, bounded corrective retrieval, and academic-first fallback behavior.
- Added [evidence-grounded hypothesis evolution](https://github.com/Siong23/ai-co-scientist/pull/76) with strategy-driven evolution, evidence inheritance, output quality gates, retry handling, and failure diagnostics.
- Fixed [Reflection and Supervisor routing](https://github.com/Siong23/ai-co-scientist/pull/89) to isolate evidence by hypothesis, filter citation IDs, preserve provenance, and keep unaccepted hypotheses out of Ranking.
- Added a [Semantic Scholar evidence fallback](https://github.com/Siong23/ai-co-scientist/pull/26) with source-ID preservation, rate-limit/error handling, and offline tests around retrieval and generation orchestration.

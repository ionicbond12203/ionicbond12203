### [Open AI Co-Scientist](https://github.com/Siong23/ai-co-scientist) — Contributor

An open-source system that coordinates specialized agents to generate, review, rank, and evolve research hypotheses using scientific-literature retrieval and local LLM inference.

My [merged contributions](https://github.com/Siong23/ai-co-scientist/pulls?q=is%3Apr+is%3Amerged+author%3Aionicbond12203) focus on:
